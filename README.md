# MIT 6.390 — Machine Learning'e Giriş Notları (Türkçe)

MIT 6.390 *Introduction to Machine Learning* ders notlarının Türkçe uyarlamasıdır.
Teknik terminoloji, kod ve matematiksel gösterimler anlaşılabilirlik için İngilizce
olarak korunmuştur.

## Çevrimiçi sürüm

GitHub Pages: <https://devozdemirhasancan.github.io/mit-6390-machine-learning-tr/>

Yerel kullanım için `index.html` dosyasını bir web tarayıcısında açabilirsiniz.

## Kaynak ve atıf

- Özgün içerik: [MIT 6.390 Introduction to Machine Learning](https://introml.mit.edu/notes/)
- Hak sahipleri: Massachusetts Institute of Technology ve 6.390 (eski adıyla
  6.036) ders ekibi
- Türkçe uyarlama, MIT tarafından onaylandığı veya resmî bir MIT yayını olduğu
  anlamına gelmez.
